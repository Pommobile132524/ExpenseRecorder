# Promo Overlay Skill — คู่มือใช้งาน

## Skill นี้ทำอะไร

ให้ Claude ทำ **ไฟล์ overlay แนวตั้ง 9:16 พื้นหลังใส (.mov)** สำหรับเอาไปซ้อนบนคลิปที่เราถ่ายเอง เพื่อโปรโมทสินค้า บริการ หรือคอร์สเรียน

เราแค่ส่ง **รูปสินค้า / บริการ / รูปโปรโมทคอร์ส** ให้ (จะแนบ **รูป reference** สไตล์ที่ชอบมาด้วยก็ได้) แล้ว Claude จะ:

1. อ่านเนื้อหาสำคัญจากรูป: ชื่อสินค้า กลุ่มลูกค้า จุดขาย ราคา (ถ้ามีในรูป) โลโก้ สีแบรนด์
2. คิดพาดหัว (hook) และประโยชน์ที่ลูกค้าได้ ให้เอง
3. **ออกแบบ layout ใหม่ให้เหมาะกับสินค้านั้น ๆ** เช่น แถบตัววิ่ง ป้ายราคา สติกเกอร์ แถบข้าง lower third กรอบ ฯลฯ — สี ฟอนต์ ของตกแต่ง และจังหวะการเคลื่อนไหว ยึดตามรูป reference ถ้ามี
4. ถามเฉพาะสิ่งที่เดาไม่ได้ (เช่น ข้อความปุ่ม CTA, จะใส่ราคาไหม) — **ไม่แต่งราคา ตัวเลข หรือคำรับประกันขึ้นเอง**
5. ส่ง **ภาพตัวอย่าง** ให้ตรวจก่อน → เราสั่งแก้ได้
6. พอโอเค จะ export เป็น **ไฟล์ .mov พื้นหลังใสสำหรับมือถือ** และตรวจไฟล์ให้ก่อนส่ง (พื้นที่กลางจอใสจริง ไม่มีเส้นขาวตอน export ใน CapCut)

ผลลัพธ์: ไฟล์ `ชื่องาน-1080x1920-15s-alpha-mobile.mov` (ประมาณ 5–15 MB) + ภาพตัวอย่าง 2 รูป

## กติกาดีไซน์ที่ skill ทำให้อัตโนมัติ

- **ส่วนบน ≤ 2/7 ของจอ** (สูงไม่เกิน 548 px) — พาดหัว hook + ประโยชน์สั้น ๆ
- **ส่วนล่าง ≤ 1/4 ของจอ** (สูงไม่เกิน 480 px) — มี **รูปสินค้า** อยู่ในส่วนนี้เสมอ + ราคา/ข้อเสนอเด่น 1 อย่าง + ปุ่ม CTA
- **ตรงกลางเว้นว่าง** ให้เห็นคลิปเต็ม ๆ
- **เอาเฉพาะรายละเอียดสำคัญ** — ข้อเสนอเดียว ปุ่มเดียว ตัดวันที่ ที่อยู่ เบอร์โทร ตัวเล็ก ๆ ออก (Claude จะบอกว่าตัดอะไรไปบ้าง)
- **ฟอนต์พาดหัวเลียนแบบรูปต้นฉบับ** — Claude จะเทียบฟอนต์ไทยกว่า 20 แบบกับพาดหัวในรูป แล้วเลือกตัวที่ใกล้ที่สุด พร้อมเลียนแบบลูกเล่น (เอียง ขอบ สองสี กล่องสติกเกอร์)
- **ถ้ารูปที่ส่งมาดูโล่ง** Claude จะออกแบบเพิ่ม (ลวดลาย แสง กรอบ สติกเกอร์ ฯลฯ) ให้ดูเสร็จสมบูรณ์
- ตอน export ระบบจะ **ตรวจขนาดส่วนบน/ส่วนล่างให้อัตโนมัติ** ถ้าเกินจะไม่ส่งไฟล์

## ใช้ได้กับเครื่องไหนบ้าง

ใช้ได้ **ทั้ง Mac, Windows และ Claude Cowork** — ได้ไฟล์ผลลัพธ์แบบเดียวกันทุกเครื่อง คือ **.mov พื้นหลังใสสำหรับมือถือ (HEVC + alpha)**

| | Mac | Windows | Claude Cowork |
|---|---|---|---|
| ใช้ผ่าน | Claude Code (แท็บ Code ในแอป Claude หรือ Terminal) | Claude Code | โหมด Cowork ในแอป Claude |
| ต้องติดตั้งเอง | Node.js 18+ | Node.js 18+ | — (มีในเครื่องจำลองของ Cowork) |
| ตัวแปลงวิดีโอ | ดาวน์โหลดอัตโนมัติครั้งแรก | ดาวน์โหลดอัตโนมัติครั้งแรก | ดาวน์โหลดอัตโนมัติครั้งแรก |
| เบราว์เซอร์สำหรับวาดภาพ | ใช้ Chrome ที่มีในเครื่อง (ถ้าไม่มีจะดาวน์โหลดให้) | ใช้ Chrome/Edge ที่มีในเครื่อง (ถ้าไม่มีจะดาวน์โหลดให้) | ดาวน์โหลดให้อัตโนมัติ |
| ตรวจไฟล์ก่อนส่ง | ✅ ตรวจละเอียดที่สุด (ใช้ตัวถอดรหัสของ Apple ด้วย) | ✅ | ✅ |

ครั้งแรกที่ใช้ต้องต่ออินเทอร์เน็ต (ดาวน์โหลดประมาณ 100–200 MB ครั้งเดียว)

## วิธีติดตั้ง

### Mac / Windows (Claude Code)

1. แตกไฟล์ zip นี้ จะได้ `promo-overlay.skill`
2. แตก `promo-overlay.skill` (เป็นไฟล์ zip) ไปไว้ที่โฟลเดอร์ skills ของ Claude Code
   - **Mac** — เปิด Terminal แล้ววาง:
     ```bash
     mkdir -p ~/.claude/skills && unzip -o ~/Downloads/promo-overlay.skill -d ~/.claude/skills/
     ```
   - **Windows** — เปิด PowerShell แล้ววาง:
     ```powershell
     Expand-Archive -Force "$HOME\Downloads\promo-overlay.skill" "$HOME\.claude\skills\"
     ```
     (ถ้า PowerShell ไม่ยอมเพราะนามสกุล .skill ให้เปลี่ยนชื่อไฟล์เป็น `.zip` ก่อน)
3. ติดตั้งเครื่องมือ (ครั้งเดียว ประมาณ 1–3 นาที):
   - Mac: `cd ~/.claude/skills/promo-overlay/scripts && npm install && node render.js --setup`
   - Windows: `cd $HOME\.claude\skills\promo-overlay\scripts; npm install; node render.js --setup`
4. **เปิดแชท Claude Code ใหม่**

> ถ้าข้ามขั้นตอนที่ 3 ไม่เป็นไร — ตอนใช้ครั้งแรก Claude จะติดตั้งให้เอง

### Claude Cowork

1. แตกไฟล์ zip นี้ จะได้ `promo-overlay.skill`
2. ในแอป Claude ไปที่ **Settings → Capabilities → Skills** แล้วอัปโหลด `promo-overlay.skill`
3. เปิดงานใหม่ในโหมด Cowork แล้วใช้ได้เลย — ครั้งแรก Claude จะติดตั้งเครื่องมือให้เองในเครื่องจำลอง (อาจใช้เวลาเพิ่มสัก 2–3 นาที)

## วิธีใช้

แนบรูปเข้าไปในแชท แล้วพิมพ์ประมาณนี้:

- `ทำ overlay ให้หน่อย` (แนบรูปสินค้า)
- `ทำ overlay โปรโมทคอร์สนี้ ยาว 20 วิ` (แนบรูปโปรโมทคอร์ส)
- `ทำ overlay สินค้านี้ เอาสไตล์ตามรูป ref` (แนบรูปสินค้า + รูป reference)
- `ทำ overlay แบบเดิม` (ใช้ดีไซน์ต้นฉบับ: พาดหัวบน + การ์ดล่างเด้งที่ 3 วิ)
- หรือเรียกตรง ๆ ด้วย `/promo-overlay`

**ถ้าแนบหลายรูป** บอกด้วยว่ารูปไหนคือสินค้า รูปไหนคือ reference (ถ้าไม่บอก Claude จะถาม)

**บอกเพิ่มได้ (ไม่บังคับ):** ความยาวคลิป, ข้อความปุ่ม (ทักแชท / สั่งซื้อ / จอง / สมัคร), ราคา-โปร, จะลง TikTok/Reels ที่มีแคปชันไหม, สีหรือฟอนต์ที่อยากได้

**สั่งแก้หลังเห็นภาพตัวอย่าง:** พิมพ์ได้ตามปกติ เช่น "พาดหัวใหญ่ขึ้น", "เปลี่ยนเป็นโทนพาสเทล", "การ์ดขยับลงล่าง", "เปลี่ยนคำเป็น…" แล้วสั่ง "โอเค export ได้เลย"

## เอาไฟล์ไปใช้ใน CapCut (มือถือ)

1. เปิดคลิปที่ถ่ายไว้ (แนวตั้ง 9:16)
2. กด **Overlay (ภาพซ้อน)** → **เพิ่ม overlay** → เลือกไฟล์ `.mov` ที่ได้
3. ขยาย overlay ให้เต็มจอ 9:16 และให้อยู่เลเยอร์บนสุด
4. ลากความยาวให้เท่าคลิป แล้ว export ได้ตามปกติ

ไฟล์ใช้ได้ทั้ง iPhone และ Mac (Final Cut, iMovie, Premiere, DaVinci) — ถ้าต้องการไฟล์ ProRes สำหรับคอมด้วย บอก Claude ว่า "เอา ProRes ด้วย"

## ปัญหาที่อาจเจอ

| อาการ | วิธีแก้ |
|---|---|
| Claude ไม่รู้จัก skill | Claude Code: เช็คว่ามี `~/.claude/skills/promo-overlay/SKILL.md` แล้วเปิดแชทใหม่ · Cowork: เช็คว่าอัปโหลดใน Settings → Capabilities → Skills แล้ว |
| ดาวน์โหลดเบราว์เซอร์/ตัวแปลงวิดีโอไม่ได้ | เช็คอินเทอร์เน็ต แล้วสั่งใหม่ — ถ้าเป็นเครื่องบริษัทที่บล็อก GitHub ให้แจ้ง IT |
| (Cowork/Linux) เบราว์เซอร์เปิดไม่ขึ้น เพราะขาดไลบรารี | บอก Claude ให้รัน `npx playwright-core install-deps chromium` |
| `npm: command not found` | ติดตั้ง Node.js จาก nodejs.org |
| แจ้งว่า `ffmpeg binary missing` | ทำตามคำสั่งที่ขึ้นบนจอ (ดาวน์โหลดตัวแปลงวิดีโอใหม่) หรือบอก Claude ให้แก้ให้ |
| ขึ้นพื้นหลังดำ/ทึบในแอปตัดต่อ | แอปนั้นไม่รองรับวิดีโอพื้นหลังใส — ลอง CapCut / แอปอื่น หรือขอ Claude ทำเป็นพื้นเขียว (green screen) |
| ปุ่ม CTA โดนแคปชัน TikTok/Reels บัง | บอก Claude ว่า "จะลงแบบมีแคปชัน ยกการ์ดขึ้นหน่อย" |
| ข้อความยาวจนดูแน่น | ให้ข้อความสั้นลง (พาดหัว ≤ ~20 ตัวอักษรต่อบรรทัด) |
